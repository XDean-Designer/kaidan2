1背景 / 目标 / 范围 / 能力映射

1.1 背景

RTB 线上开单结账经过一段时间运营，线下调研反馈：

  • 常规开单需先选顾客、选项目、配员工、填备注，流程较长，存在「只想快速收一笔钱」的场景；
  • 顾客卡片与顾客列表在性别表达、头像素材上体验欠佳；
  • 会员所持权益信息默认折叠，收银员核对权益时需要额外操作；
  • 添加项目/产品时的信息组织与操作路径不符合当前门店操作习惯；
  • 直接收款缺少结算第二步、流水展示、退款与业绩/提成配置等闭环展示。

本期在不改变其他功能逻辑的前提下，对开单结账做定点优化，并为直接收款补齐逻辑补充页面。

    3. 全部项目或全部产品可用的优惠券（如新人8折券：满 58 减 10）；
    4. 直接收款金额符合使用门槛的代金券（如满200减30券：金额 ≥200 才可选，减 30）。
  • 金额不满足门槛的代金券在列表中置灰不可选；选择权益后应付 = 原金额按规则折算，取消权益恢复原价；权益选择不算改价（可继续改小计）。

8业务规则

  1. 身份切换：默认散客（文案「散客」、单默认头像）；选会员 → 会员；选男/女散客 → 散客性别态（对应单头像）。s2/s3/s6/s7 顶部卡片随身份切换，后续元素随卡片高度下移。
  2. 散客默认态：未选择顾客时为单默认头像 +「散客」；订单记为「散客」。从列表选男/女散客后仅显示对应单头像 + 文案；点击头像/姓名进 s4；性别切换仅通过 s4。
  3. 会员卡权益：持卡列表默认收起、右侧 chevron 展开/收起（展开＝一行一张卡：卡类型+卡名 | 剩余权益，内容与线上一致）；移除「办卡」「更换顾客」按钮（入口为点头像/姓名进 s4）。
  4. VIP 标签：按最新 Figma 资源（渐变 ◆VIP）适配尺寸与位置；开发保持该位置现有 VIP 标签逻辑不变。
  5. 金额格式：整数≤6 位、小数≤2 位、上限 999999.99、禁「.」开头、前导 0 剔除、不可为负。
  6. 直接收款：空金额不可「去收款」（toast「请先输入金额」）；员工/开单内容选填；金额按原价计算，不做身份折扣；不可挂单；与小程序「自助买单」的纯金额支付不是同一种功能，互不相关。
  7. 挂单限制：购物车未添加任何物品时不可挂单；直接收款流程（含 s7）不可挂单。按钮置灰，点击 toast 提示原因。s1/s5/s6 挂单成功 → 写入挂单池 + 清空购物车 + toast「挂单成功」+ 跳 s14 挂单列表。
  8. 单号：s6/s7 无手工单号卡片（本轮删除）；单号在 s15 成功页「改单号」 维护（数字、1-20 位、留空恢复自动生成）。
  9. 无产品 Tab：价目表未录入产品时，开单页仅显示「项目」且居中；两个价目表都空 → 两个 Tab 都显示 + 空态说明（管理入口本期仅说明）。演示开关 ?noProduct=1 / ?noProject=1。
  10. 应付/小计编辑：带笔形编辑图标；对焦即清空、失焦为空还原；改价后 s6/s7 该明细权益锁定（toast「改价商品不可用权益」）；改价判定以「单价 / 权益优惠价」× 数量为基准。
  11. 权益自动匹配（s6）：明细未改价且未手动清除时，会员自动匹配其持有的全场最优折扣权益（演示为超值折扣卡 8 折，与价目划线价同源）、散客自动匹配首张优惠券；手动取消后不再自动覆盖。
  12. 数量：商品「设置内容」sheet 内步进 1~999；点「取消」/ 遮罩关闭 = 丢弃草稿（不写入购物车）。
  13. 员工选择：两步翻转（点客/散客 → 小工/中工/大工）；多选；同一商品重进保留已选；跨商品（另一商品/行）打开时以该商品自身数据渲染、不继承其它商品的已选与中途翻牌态；回填「姓名·点客·大工」。
  14. 员工选择跨商品隔离：商品「设置内容」sheet 的员工面板始终以该商品自身的草稿数据渲染；切换商品打开时为「未设置、可重新设置」的干净状态，且每次打开都会清空遗留的卡片翻牌编辑态。
  15. 商品设置内容 sheet：点商品圆形加号 → 底部 sheet（数量 / 应付 / 服务员工），点「确定」写入购物车；原「行内展开区 + 滚动视差吸顶」方案整体删除。
  16. 快捷添加会员（s4「添加会员」行下展）：姓名* + 手机号（选填，^1[3-9]\d{9}$ 校验）+ 性别*（男/女）；只填姓 + 选性别 → 自动「*先生 / *小姐」；取消不保存，确认后按姓氏拼音归组新建会员行并定位展开；与顾客行展开互斥。
  17. 购物车明细回跳编辑：点明细行体 → 回开单页并打开该商品的「设置内容」sheet 回填保存的数据（可再编辑），重新提交为「更新该笔（替换）」；行内 ± 步进器不触发跳转。
  18. 直接收款权益（s7）：默认自动匹配（会员=其持有的全场最优折扣权益，演示为 8 折；散客=「无卡权益」，与 s6 一致）；可改选类型=会员卡储值金额、全场项目适用的计次或折扣、全部项目或全部产品可用的优惠券、满足金额门槛的代金券；门槛不满足的代金券置灰不可选；选权益后应付按规则折算（储值/折扣按比例、满减券减额、计次不抵扣金额），选「不使用权益」恢复原价且不再被自动覆盖；权益选择不算改价。
  19. 会员权益价（划线价）：会员持有的折扣权益使价目项目/产品产生划线价（原价灰色划线 + 红色优惠价）；添加 sheet「应付」默认 = 优惠价 × 数量（默认优惠价不算改价）；散客无权益不划线。
  20. 散客卡头像 / 文字：点击头像或「散客 / 男散客 / 女散客」文字均进入顾客列表（s4）；不再支持卡片上点头像切换性别。
  21. 经营分析关联：直接收款不计入「经营分析 → 门店经营报表」的项目 TOP5 排行（经营分析属另一产品线，本侧记录该规则）。
  22. 开单内容：≤50 字；空/全空格视为未填。
  23. 购物车：加购后应付累加、分类角标 +1；s6 删除明细同步扣减角标与应付；结账成功进入 s15 并清空。
  24. 下一步：购物车有项 → 进入 s6 开单结算；无项 → toast「请先选择项目」。
